About This Project

This project combines a career roadmap, resume analysis, and interview preparation workflow into a single AI-powered career assistant. It uses structured JSON data for reliable role information and unifies the user experience around a common target role and skill journey.

The app follows a hybrid design: fixed job and resource data remain in local JSON files, while Gemini can be used for personalized reasoning when configured. This makes the application easier to maintain and more resilient when AI services are unavailable.
